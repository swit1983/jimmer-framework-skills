# 查询篇

在这个章节中，我们将会在不考虑[缓存](https://babyfish-ct.github.io/jimmer-doc/zh/docs/cache)的情况下介绍Jimmer中各种查询。

其中，有三个功能是颠覆性的

-   [对象抓取器](https://babyfish-ct.github.io/jimmer-doc/zh/docs/query/object-fetcher)

    一句话查询任意形状的数据结构，就如同GraphQL所做的那样。

-   [动态表连接](https://babyfish-ct.github.io/jimmer-doc/zh/docs/query/dynamic-join)

    这是一个巨大的行业缺失，该功能可以让你轻松书写任意复杂的动态查询。

-   [智能分页](https://babyfish-ct.github.io/jimmer-doc/zh/docs/query/paging)

    用户只关注查询原始数据，行数查询会被自动生成并优化，非常便利。
